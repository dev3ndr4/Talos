# Talos Sandbox

Isolated execution environment for the Talos Coding Agent.

## Security & Isolation

The sandbox is a minimalist Python environment designed to execute scripts generated by the Coding Agent.

- **Filesystem Isolation:** The agent can only read/write to the `/workspace` directory.
- **Network Isolation:** In production, this container should have restricted outbound access (configured via Docker networks).
- **Resource Limits:** Docker resource limits should be applied to prevent runaway processes.

## Usage

The `backend` service communicates with the `sandbox` via internal bridge networking to dispatch code execution tasks and retrieve output/logs.
